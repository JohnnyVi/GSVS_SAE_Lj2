# Datenbank-Skript (2. Lehrjahr)

Dieses Repository enthält das Datenbank-Skript von Herrn Vöhringer für das 2. Lehrjahr der Fachinformatiker an der Gewerbeschule Villingen-Schwenningen.

## Ziel des Repositories

- Zentrale, digitale Lernunterlage für Unterricht und Nachbereitung
- Schneller Zugriff auf alle Kapitel in sinnvoller Reihenfolge
- Erweiterbare Basis für weitere Inhalte (Übungen, Lösungen, Projekte)

## Einstieg

- Startseite für GitHub Pages: [GitHub Pages](https://johnnyvi.github.io/GSVS_SAE_Lj2/)
- Kapitel liegen im Ordner: [Skript](Skript/)

## Struktur

- [README.md](README.md): Allgemeine Hinweise und Orientierung
- [GitHub Pages](https://johnnyvi.github.io/GSVS_SAE_Lj2/): Landingpage mit Themen-Navigation
- [config.yml](config.yml): Basis-Konfiguration für die Pages-Darstellung
- [Skript](Skript/): Fachliche Inhalte als einzelne Kapiteldateien

## Wichtige Hinweise zum Lernen

- Die Kapitel bauen inhaltlich aufeinander auf. Empfehlung: in numerischer Reihenfolge lesen.
- SQL-Beispiele am besten immer selbst in einer Testdatenbank nachbauen.
- Nicht nur Abfragen kopieren, sondern Ergebnisse aktiv erklären können.
- Sicherheitsthemen wie SQL Injection sind Pflichtwissen für Praxis und Prüfung.

## Hinweise zu GitHub Pages

- Einstiegspunkt ist die [GitHub Pages-Seite](https://johnnyvi.github.io/GSVS_SAE_Lj2/).
- Falls später Jekyll-Optionen benötigt werden, kann aus [config.yml](config.yml) eine Datei mit dem Namen _config.yml werden (Jekyll-Standardname).
